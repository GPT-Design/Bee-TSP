You’re close—your GRASP is fine, but a few things can blow it up to multi-million tours:

* You ignore `candidate_adj`, so you sometimes jump to very far cities early.
* If `dist.d` ever returns non-finite (inf/NaN) or squared distances, the RCL can admit junk.
* With outliers, `threshold = d_min + α(d_max-d_min)` can include far-away nodes; if `rcl` ends up empty you’ll crash or (in other code) fall back poorly.

Here’s a hardened, drop-in version that:

* Uses the candidate list first (falling back to all unvisited).
* Guards against non-finite distances.
* Falls back to nearest neighbor if the RCL is empty.
* Works with NumPy RNG explicitly and clamps `alpha`.

```python
import numpy as np
from typing import Dict, List

def randomized_greedy(
    n: int,
    dist,  # expects .d(u, v) -> float
    candidate_adj: Dict[int, List[int]],
    alpha: float = 0.30,
    rng: np.random.Generator = None,
) -> List[int]:
    """
    GRASP construction heuristic (robust).
    - Prefers candidate neighbors; falls back to all unvisited.
    - Handles NaN/inf distances.
    - Falls back to nearest neighbor if RCL is empty.
    """
    if rng is None:
        rng = np.random.default_rng()

    # clamp alpha to [0,1]
    alpha = float(min(1.0, max(0.0, alpha)))

    start = int(rng.integers(0, n))
    tour = [start]
    unvisited = set(range(n))
    unvisited.remove(start)

    while unvisited:
        current = tour[-1]

        # prefer candidate neighbors first
        neigh = [v for v in candidate_adj.get(current, []) if v in unvisited]
        if not neigh:
            neigh = list(unvisited)

        # compute distances (float) and guard non-finite
        dists = np.array([float(dist.d(current, v)) for v in neigh], dtype=float)
        finite_mask = np.isfinite(dists)
        if not np.any(finite_mask):
            # if everything is bad, fall back to all unvisited by nearest neighbor
            neigh = list(unvisited)
            dists = np.array([float(dist.d(current, v)) for v in neigh], dtype=float)
            finite_mask = np.isfinite(dists)

        # restrict to finite candidates
        neigh = [neigh[i] for i in range(len(neigh)) if finite_mask[i]]
        dists = dists[finite_mask]

        # nearest-neighbor fallback if something odd happens
        if len(neigh) == 0:
            # pick arbitrary remaining node to keep going
            next_city = int(rng.choice(list(unvisited)))
            tour.append(next_city)
            unvisited.remove(next_city)
            continue

        d_min = float(dists.min())
        d_max = float(dists.max())

        if d_max == d_min:
            # all equal distances; any is fine
            rcl_idx = np.arange(len(neigh))
        else:
            threshold = d_min + alpha * (d_max - d_min)
            rcl_idx = np.where(dists <= threshold)[0]

        if rcl_idx.size == 0:
            # build a small RCL from the K nearest if thresholding failed
            K = max(1, min(10, len(neigh)))  # small, greedy-biased
            rcl_idx = np.argsort(dists)[:K]

        # choose randomly from RCL
        choice_idx = int(rng.choice(rcl_idx))
        next_city = int(neigh[choice_idx])

        tour.append(next_city)
        unvisited.remove(next_city)

    return tour
```

Quick checks to keep your lengths ~500k:

1. Ensure `dist.d(u, v)` returns true metric distances (not squared). If it’s squared, either take `sqrt` inside `dist.d` or replace `dists` with `np.sqrt(dists)` above (only if all non-negative and you know they’re squared).
2. Confirm symmetry & zeros: `d(u,u)=0`, `d(u,v)=d(v,u)`, all finite.
3. Use candidates: pass a k-nearest adjacency (e.g., k≈20–40) into `candidate_adj`.
4. Seed for reproducibility:

   ```python
   rng = np.random.default_rng(42)
   tour = randomized_greedy(n, dist, candidate_adj, alpha=0.3, rng=rng)
   ```
