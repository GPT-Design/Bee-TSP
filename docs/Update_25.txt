Patch plan (single source of truth for metric)
1) Wire the metric once, at startup

Read EDGE_WEIGHT_TYPE from <instance>.tsp → metric_tag.

Store in a global, immutable config (or inject into all modules).

# at run init
metric_tag = read_tsplib_metric(f"benchmarks/{instance}.tsp")  # 'EUC_2D' | 'CEIL_2D' | 'ATT' | 'GEO'
config.metric_tag = metric_tag
log.info({"metric_tag": metric_tag})

2) Replace all ad-hoc distance calls with a single factory

Create a Distance object once and pass it everywhere (gain calc, local search, candidate builder, POPMUSIC, HK, etc.).

class Distance:
    def __init__(self, metric_tag, coords):
        self.metric = metric_tag
        self.coords = coords
        self._f = {"EUC_2D": self._euc, "CEIL_2D": self._ceil, "ATT": self._att}[metric_tag]
    def _euc(self, i, j):  # integer
        x1,y1 = self.coords[i]; x2,y2 = self.coords[j]
        return int(round(((x1-x2)**2 + (y1-y2)**2)**0.5))
    def _ceil(self, i, j):
        x1,y1 = self.coords[i]; x2,y2 = self.coords[j]
        return int(-(-(((x1-x2)**2 + (y1-y2)**2)**0.5) // 1))  # ceil
    def _att(self, i, j):
        x1,y1 = self.coords[i]; x2,y2 = self.coords[j]
        rij = (((x1-x2)**2 + (y1-y2)**2)/10.0) ** 0.5
        t = int(round(rij));  return t if t >= rij else t+1
    def d(self, i, j): return self._f(i, j)


Do not pick metric inside hot paths; use dist.d(i,j) everywhere.
