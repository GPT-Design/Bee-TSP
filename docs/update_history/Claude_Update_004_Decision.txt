## 4) Adaptive Overlap + Portals (LITE, no zoning refactor)

**Goal:** improve cross-zone connectivity without changing zone membership.

**Files:** wherever candidate adjacency is built/applied.

* Config:

  ```yaml
  solver:
    zones:
      adaptive_overlap:
        enabled: true
        portal_pct: 2.0     # top % boundary nodes to treat as portals
  ```
* Algorithm (post-zoning, pre-search):

  1. For each node, detect if it has any **k-NN neighbor** in a different zone → mark as **boundary**.
  2. Score boundary nodes:
     `score = (# cross-zone neighbors in k-NN) + EHM_edge_count(node)` (use 0 if EHM not present).
  3. For each zone, pick top `portal_pct`% by score.
  4. **Augment candidate graph** only: for each portal, add its k nearest neighbors from adjacent zones into its candidate set (do **not** duplicate nodes or change zone labels).
* No sklearn. Reuse existing k-NN candidate lists. If missing EHM, ignore that term.

Deliverable: `zones.adaptive_overlap.enabled` adds cross-zone candidates; no structural changes.

## 6) Recombination (EAX-LITE = UCR)

**Goal:** provide a minimal, EAX-like recombination without full EAX complexity.

**Files:** `bee_tsp/integrators/ucr.py` (new) + switch in solver

* Config:

  ```yaml
  integrator:
    method: "popmusic"   # default
    ucr:
      parents: 6
      children_per_pair: 1
      repair_budget_ms: 50
  ```
* Algorithm (Union-Cycle Recombine):

  1. Given parents A,B, compute **U = edges(A) ∪ edges(B)**; find **symmetric-difference cycles** (AB-cycles) by walking degree-2 nodes.
  2. Flip each cycle (or a random subset) to build child.
  3. Run bounded 2-opt repair on **candidate-union graph** (time-cap `repair_budget_ms`).
  4. Keep best child.
* Hook: add `integrator.method: "ucr"` path; keep POPMUSIC as default. No external deps.

Deliverable: working “ucr” option that’s simpler than full EAX.
