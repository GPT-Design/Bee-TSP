0) Why this update
We’ve sunset MH; SH is the production path. This sprint focuses on: (i) tighter candidate sets & portals, (ii) robust HK 1-tree bounds in integer units, and (iii) better early-phase anytime slope via seed/initializer diversity — all under our strict evaluation & output guardrails.

1) Objectives (measurable)
O1. **Early slope**: +0.5–1.0× median Δgap%/min in first 10 min on pr2392@600s and fnl4461@1800s (vs current SH baselines).
O2. **TTT@10%**: pr2392@900s hits TTT@10% in ≥2/3 seeds.
O3. **Long-wall stability**: pla33810@5400s achieves ≤ current SH median best_len (no regressions) with stricter candidate caps & portals.
O4. **Telemetry**: HK dual-gap timelines (integer units) captured per epoch; no NaNs; time integrity OK.

2) Scope (no algorithm detours)
- Single-Hive only. No island code changes. No EAX/learning/soft-pheromone in production (see §7 backlog).
- All code must pass Updates 15/17/19/20 guardrails.

3) Work items (implementation)
W1. **Candidate Manager v1.2 (SH)**
  - Union graph: **Delaunay ∪ k-NN**, with autoscale `k_base` by n (suggest: n<3k→24, 3k–10k→30, >10k→36), then apply global cap.
  - **Edge cap per node**: enforce `cap ∈ {8,10}` after union; drop longest excess edges (ties: prefer Delaunay).
  - **Portals** (cross-zone connectors): per node `P∈{3..7}`; rank by length, Delaunay presence, & (optional) 1-tree incidence (see W2).
  - Assert/Log: per-node degree histograms; cap violations must be 0.

W2. **HK 1-tree bound (integer units)**
  - Compute sparse 1-tree LB on the **candidate union graph** (not full graph) with integer weights (EUC_2D/CEIL_2D/ATT/GEO).
  - Emit per-epoch: `{LB, dual_gap_pct=100*(Lchamp-LB)/LB}`, stall flag if Δ dual-gap ≤ ε across one epoch (ε default: 0.1–0.2%).
  - Time budget: ≤ 3–5% of wall per run (accumulated). If over, reduce iterations adaptively.
  - Optional: count edge hits in 1-tree to **nudge portal ranking** (do not increase cap).

W3. **Late-only Or-opt (consolidate)**
  - Controller time-gate (SH):  
    0–50%: forbid • 50–80%: allow **intra-zone only**, protect portals  
    ≥80%: **one** global pass, require integer gain τ ≥ 3–5; protected portals removable only ≥80% and if τ met.
  - Log: Or-opt survival % to final tour; count protected-edge deletions with ΔL_int.

W4. **Initializer diversity for anytime slope**
  - For each seed, build **K initial tours** with small budgets; pick best to start. K defaults: 3–4.
  - Mix: nearest-neighbor, nearest-insertion, farthest-insertion, random greedy (+ quick 2-opt polish).
  - Budget per initializer: ≤ 1–2% of wall; total ≤ 5%.
  - Log: initializer winner & per-initializer best_len_int.

W5. **Output & integrity (no-regression)**
  - All runs via `output_app.py`; update `<base>.json` to include `init_mix:{K, winner}` and `candidate_caps:{cap, portals}`.
  - Keep parity triad; strict integer SSoT; No-NaN; time integrity checks per Update 19.
  - CI: fail on any candidate cap violation; fail if HK dual-gap fields missing when HK was enabled.

4) Experiments (exact)
E1. **Short-wall (primary)**
  - pr2392 @600s (SH) seeds 42/123/456 → measure early slope (0–10m), improvements/min, best_len_int.
  - pr2392 @900s (SH) same seeds → TTT@10% target.
  - fnl4461 @1800s (SH) same seeds → early slope, best_len_int.
E2. **Long-wall sanity**
  - pla33810 @5400s (SH) seeds 42/123/456 → ensure ≤ current SH median best_len; examine dual-gap timelines.
E3. **Ablations (fast, pr2392 @600s)**
  - A1: `cap=8` vs `cap=10`.
  - A2: portals/node `3` vs `5` vs `7`.
  - A3: K initializers `2` vs `4`.
  - A4: HK on vs HK off (confirm overhead/slope tradeoff).

5) Success gates (pass/fail for Update 23)
G1. **Early slope:** pr2392@600s median early slope improves by ≥ +0.5× vs current SH baseline; fnl4461@1800s ≥ +0.3×.
G2. **TTT@10%:** pr2392@900s hits in ≥2/3 seeds.
G3. **No regressions:** pla33810@5400s median best_len **not worse** than current SH median; telemetry complete.
G4. **Integrity:** 0 NaNs; candidate cap violations = 0; time integrity = OK; manifest lines valid; tour SHA/length verified.
